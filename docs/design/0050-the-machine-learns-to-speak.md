## 1. The one-line brief

The machine's human-facing sentences leave the code and become **governed
craft on the shelf** — then the wounded cards get rewritten in human speech
through the machine's own edit doors, and the first UAT persona stands up to
keep wounding them forever. After this dive, tuning what the machine says is
an edit at a gate, never a code change: the season's every later receipt
compounds instead of hard-coding.

The judge (0049 §1): a person who's never heard the words "worldline" or
"epoch." The card must say — *what happened · what is asked of you · what
each button does · what happens next* — with evidence a human can weigh,
never bare hashes.

## 2. The laws

1. **The sentence is craft.** Wave-1 families — the WAITING-ON-YOU gate
   cards (calibration · tamper/walk-back · joins · commissions · releases ·
   charter/reflex cards) and the parlor's system notes (dispatcher choices,
   mechanics speech) — become becky-signed genesis craft records with
   ⟦slots⟧, exactly 0045's firmware extraction aimed at the glass. The
   worker composes card texts by `craft()` render; code literals survive
   only as the genesis fallback.
2. **Facts ride slots, never prose.** A sentence template carries ⟦slots⟧
   for every fact (names, counts, gaps, evidence); an unfilled slot refuses
   to render (the jacket's law, 0047 sp2). No fact is ever baked into a
   template — so an edited sentence can never lie about data.
3. **One law of change, the lighter lane.** Card sentences are the
   machine's SPEECH, not its cognition: they ride grace's shelf like
   `fingertip-default` — one-motion sibling edits at the human's gate —
   **not** the Canon epoch ceremony (0045 reserved that for driving words;
   a card text drives nothing, so a release that renames the machine would
   be false gravity). Design call under "you own the approach" (JB,
   2026-08-11) — reversible if JB re-locks.
4. **Refusals stay one-faced and OUT of wave 1** (L3 as locked): the
   uniform-refusal law (0002 §4) means refusal texts must stay identical
   across causes — they enter the shelf only as ONE object, later, with
   that law encoded as a conformance test before any edit door touches it.
5. **The persona is craft too.** The UAT walker's voice, expectations, and
   patience live as a craft record — so tuning the tester rides the same
   gates as tuning the tested.
