## 1. What stands today (the honest map, 2026-08-20)

- **One gateway, everywhere.** Every governed thought — a resident's voice, a
  desk stage, a mentor, a judge, quinn's eye — walks `/model/authorize
  {token, class, est_tokens, model?}` → `ModelPlane::resolve(class, pin)` →
  litellm executes → `/model/meter` reconciles. Stalls route first; the legacy
  `profiles/model-registry.json` answers only classless floors. Sunset is
  structurally unservable. This is the enterprise doc's "two-stage routing,"
  already built.
- **Classes are the virtual routes**: `low / medium / high / xhigh` — the very
  words the Objectives Logic dial speaks. **But the dial's `effort` field rides
  the request UNREAD** — no code maps effort → class. The freight this dive
  was always going to carry.
- **Stalls are deployments**: pinned deal (pricing · context · modalities),
  provider DID, five-state lifecycle with governed transitions, canary that
  EARNS service, worldline records (ada authors; a mind never self-attests),
  restart-durable ledger. Drift deprecates and stages re-approval; announced
  expiry stages a fit-ranked swap recommendation. (The decom-HITL JB
  remembered — it is real, and it is good.)
- **The catalog has one eye**: OpenRouter's public list, cached. No Anthropic,
  no OpenAI, no Hugging Face, no AWS. Meanwhile litellm's LOCAL cost map
  carries **3,055 models with pricing, context, and capability booleans —
  268 of them Bedrock** — shipped in the package, read by no one.
- **Allocation is invisible and hard-coded**: residents climb a fixed
  low→medium→high ladder at call time; desk pipeline stages carry class
  literals in code; the mentor/judge pair are constants. No record anywhere
  says *who uses what* — so a retirement cannot know its blast radius, and the
  resident room's Model tab honestly confesses: *"a mind swap rides ada's
  gate; the picker joins when that door opens."* That door opens now.
- **The glass**: seven flat stacked sections, no master-detail, no reading
  pane; a staged swap's recommendation arrives as prose in `r.text` and is
  never rendered as the decision it is.

## 3. The laws of 0058

1. **Intel is never authority.** A catalog entry can be searched, compared,
   and selected — but nothing serves until saddled, attested, and earned
   through the canary. Discovery adapters are read-only by construction; they
   never execute application inference. Field-level precedence when sources
   disagree: provider's own API > serving router (OpenRouter/HF) > litellm's
   local map — and every source kept with provenance, never discarded.
2. **A missing model is not a dead model.** One refresh omitting an entry
   marks it `missing` and counts consecutive misses; retirement of intel needs
   a threshold or explicit shutdown evidence. (The metabolism's instinct,
   applied to the market.)
3. **Effort IS class.** The Logic dial's `low/medium/high/xhigh` maps 1:1 onto
   the model classes — one vocabulary, spoken at the composer, honored at the
   gateway. An objective's effort rides its plan into every leg's authorize.
4. **The assignment is a governed record.** `subject → class (+ optional pin)`
   where subject is a resident name, a capability key, a floor scope, or the
   universe default. Resolution walks: subject pin → subject class → floor
   default → **universe default (the LAW at the apex — JB's word: attributes
   of a provider:llm set once, honored everywhere)**. Ada stages, the human
   gates, the ledger keeps, the worldline remembers.
5. **No retirement without a blast radius.** Every eol/swap/retire card names
   who is assigned to and who has recently used the mind (assignments +
   meter), before the human's word. Continuity is not a report — it is the
   decision's own furniture.
6. **The market speaks when spoken to.** The catalog refresh is on the beat
   with TTLs and disk cache; ada's NLP answers ride the existing governed
   voice under her DID and the standing ceilings. No new spend paths.
7. **AWS is read, not wired** (JB's pin): Bedrock entries appear from the
   local map marked `read-only — not hooked up`; the live adapter is a named
   future dive. The adapter seam stays open for every next provider.
