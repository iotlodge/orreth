## The house rules the guides assume

- **Humans never read the world; they ask it** (0020). Every example below is an ask.
- **Everything lands signed** — asks, answers, moments, proposals. The record is the
  universe's memory of itself; nothing here is a side channel.
- **Consequence waits for humans** (0012). Where a flow pauses for you, that pause
  is the design working, not a bug: silence is denial.
